# Support

Repo Magical Kingdom is community-supported open-source software.

## Where to ask

- Use [GitHub Discussions](https://github.com/parrisdigital/repo-magical-kingdom/discussions)
  for setup questions, ideas, and world-design conversation.
- Use the structured
  [issue forms](https://github.com/parrisdigital/repo-magical-kingdom/issues/new/choose)
  for reproducible bugs, feature proposals, performance reports, and asset
  contributions.
- Use [private vulnerability reporting](SECURITY.md) for security concerns.

Before asking for help, search existing issues and include your operating
system, Node and pnpm versions, browser/GPU details for rendering problems, the
repository input if it is public, and the exact error message.

Support is provided on a best-effort basis with no guaranteed response time.
Please do not send private repository contents, credentials, or personal data.
