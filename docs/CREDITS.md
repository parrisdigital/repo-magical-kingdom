# Credits

Repo Magical Kingdom is created and maintained by
[Parris Digital](https://github.com/parrisdigital) with contributions from its
open-source community.

## Product lineage

- [Repository City](https://github.com/parrisdigital/repository-city) — the
  original repository-to-place project and architectural predecessor, MIT.
- [WorldClaw](https://github.com/Tencent-Hunyuan/Hunyuan3D-WorldClaw) — research
  inspiration for structured, coarse-to-fine 3D world planning. Cited as
  research only; no code or assets are redistributed.
- [Tiny World Builder](https://github.com/jasonkneen/tiny-world-builder) —
  procedural-system reference for explicit world scale, deterministic terrain,
  LOD boundaries, and bounded animal wandering, AGPL-3.0. No code or assets are
  redistributed.

## Project identity

- [ShieldCN](https://shieldcn.dev/) — live, theme-aware README badges, MIT.
- OpenAI image generation — project-owned Four-Season Cycle application mark
  and Orbital Mountain favicon, generated from the project's own registered
  artwork and distributed under CC BY 4.0 with full prompt/hash provenance.

## World art and wildlife

- [Quaternius Medieval Village MegaKit](https://quaternius.com/packs/medievalvillagemegakit.html)
  — textured modular architecture and village props, CC0-1.0.
- [Quaternius Stylized Nature MegaKit](https://quaternius.com/packs/stylizednaturemegakit.html)
  — textured trees, plants, flowers, rocks, and path details, CC0-1.0.
- [Quaternius Ultimate Animated Animal Pack](https://quaternius.com/packs/ultimateanimatedanimals.html)
  — animated deer, fox, and stag wildlife, CC0-1.0.
- [Kenney Nature Kit 2.1](https://kenney.nl/assets/nature-kit) — paired green
  and autumn trees plus seasonal ground accents, CC0-1.0.
- [Kenney Holiday Kit 2.0](https://www.kenney.nl/assets/holiday-kit) — snowy
  tree silhouettes and generic snow treatments, CC0-1.0.
- [Poly Haven](https://polyhaven.com/) — Sparse Grass by Amal Kumar, Dirt Floor
  by eye-candy.xyz, and Rocks Ground 02 and Coast Sand 01 by Rob Tuytel provide
  the packed grass, soil, rock, and shore PBR terrain channels, CC0-1.0.
- [Poly Haven architecture detail](https://polyhaven.com/textures) — White
  Plaster 02 by Rob Tuytel; Brick Wall 005 by Dario Barresi and Dimitrios Savva;
  Wood Table 001 by Dimitrios Savva and Rico Cilliers; and Roof Tiles by Stephan
  Seeliger provide plaster, brick, wood, and roof-tile detail, CC0-1.0.
- [Poly Haven Kloofendal Overcast (Pure Sky)](https://polyhaven.com/a/kloofendal_overcast_puresky)
  by Greg Zaal — optional neutral daylight reflections and image-based lighting,
  CC0-1.0; never used as the visible background.

The selected models are transformed into optimized runtime GLBs. Exact files,
hashes, modifications, and preserved license texts are recorded in the
[asset-pipeline documentation](ASSET_PIPELINE.md),
[seasonal asset playbook](SEASONAL_ASSET_PLAYBOOK.md), and machine-readable
registry.

The exact Poly Haven source URLs, authors, source hashes, physical dimensions,
atlas layout, and browser budgets are recorded in the
[terrain PBR documentation](assets/TERRAIN_PBR.md) and
[architecture detail PBR documentation](assets/ARCHITECTURE_DETAIL_PBR.md).
The environment source, hash, and memory contract are recorded separately in
the [environment HDRI documentation](assets/ENVIRONMENT_HDRI.md).

## Runtime foundation

- [Three.js](https://threejs.org/) — WebGL and 3D engine foundation, MIT.
- [React Three Fiber](https://r3f.docs.pmnd.rs/) — React renderer for Three.js,
  MIT.
- [Drei](https://github.com/pmndrs/drei) — React Three Fiber helpers, MIT.
- [Next.js](https://nextjs.org/) — web application framework, MIT.
- [React](https://react.dev/) — application interface, MIT.
- [Zod](https://zod.dev/) — runtime validation, MIT.
- [Zustand](https://zustand.docs.pmnd.rs/) — state management, MIT.

Exact versions, commits, relationship types, and usage locations are maintained
in the machine-readable
[`attribution/registry.json`](../attribution/registry.json). Git history is the
canonical record for individual project contributions.

Future asset creators will be listed here and in the application Credits
experience according to [the asset policy](ASSET_POLICY.md).
