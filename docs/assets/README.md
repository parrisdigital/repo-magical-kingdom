# README and social artwork

This directory documents release artwork provenance. The approved release
artwork is now distributed from `public/`:

- `public/readme-hero.png` — 1942 × 809 README banner showing the complete
  repository-universe-to-kingdom journey
- `public/social-preview.png` — centered 1280 × 640 social crop

Both files are original, accessible, and registered in
`attribution/registry.json`, including the image-generation tool, date, full
prompt, source-capture hash, review, conversion steps, and final content hashes.

The README title remains real text. The banner contains no essential
instructions, copied WorldClaw imagery, third-party logos, fake application UI,
or generated readable source code. Its planets are uninhabited overview worlds;
the inhabited kingdom is a separate enterable landscape.
